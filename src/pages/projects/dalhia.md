Dalhia Brand is a full stack e-commerce project for a clothing brand, built to connect a product catalogue, shopping cart, checkout flow and order tracking in a single web application.

- Built the frontend with Angular and deployed it on Vercel.
- Developed the backend with Django, PostgreSQL and containerized services with Docker.
- Implemented product detail pages, size selection, cart management and order tracking.
- Integrated Redsys as the secure payment gateway.
- Managed deployment infrastructure across AWS and Vercel with Git-based version control.

The application is currently offline while I focus on other work, but it remains one of my most complete full stack projects.
